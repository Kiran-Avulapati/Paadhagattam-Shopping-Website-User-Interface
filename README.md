# Paadhagattam Shopping Website – User Interface

A responsive shopping website user interface developed using **HTML, CSS, and JavaScript**.  
The project provides a simple and visually appealing e-commerce-style interface for browsing footwear and related products.

## 🌐 Live Demo

[View Live Website](https://kiranavulapati.github.io/Paadhagattam-Shopping-Website-User-Interface/)

## 📌 About the Project

**Paadhagattam Shopping Website** is a front-end web development project designed to demonstrate the creation of an online shopping interface.

The website allows users to explore different footwear products through dedicated pages and interact with a simple, structured shopping interface.

The project focuses on:

- Clean and user-friendly interface
- Product presentation
- Multiple web pages
- Responsive styling
- JavaScript-based interactions
- Organized HTML, CSS, JavaScript, and image assets

## ✨ Features

- 🛍️ Shopping website user interface
- 👟 Footwear/product showcase
- 📱 Responsive web design
- 🖼️ Product images and visual content
- 📄 Multiple web pages
- 📩 Contact page
- 📦 Product collection page
- ⚡ JavaScript-based interactions
- 🌐 Hosted using GitHub Pages
